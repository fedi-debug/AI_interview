## 🎯 Overview

**HireNest** is a comprehensive interview assessment platform that runs completely offline on Windows. It combines:

1. **MCQ Assessment** - 20 role-specific multiple-choice questions generated by Llama 2
2. **Live AV Interview** - Real-time audio/video interview with:
   - Natural speech synthesis (KittenTTS - lightweight, ONNX-based)
   - Automatic speech recognition (faster-whisper)
   - Prosody analysis (emotion, fluency detection)
   - Non-verbal cues (MediaPipe pose/hand detection)
   - AI follow-up questions based on responses
   - Fused multi-modal scoring

**Perfect for:** Recruitment automation, technical interviews, HR screening, candidate evaluation.

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🤖 **AI-Powered Questions** | LLM generates contextual MCQs and interview questions |
| 🎙️ **Speech Recognition** | Real-time speech-to-text with faster-whisper |
| 🗣️ **Natural TTS** | KittenTTS with 8 voices (Bella, Jasper, Luna, Bruno, Rosie, Hugo, Kiki, Leo) |
| 📊 **Multi-Modal Scoring** | Content + Fluency + Prosody + Non-verbal analysis |
| 🎥 **Video Analysis** | Pose detection, hand gestures, attention tracking |
| 📱 **Real-time Streaming** | WebSocket-based audio/video streaming |
| 💾 **Offline Operation** | No internet required after initial setup |
| 🔒 **Privacy First** | All data stays local on your machine |
| 🏠 **Windows Compatible** | Optimized for Windows 10/11 with GTX 1650+, i5+ |
| ⚡ **Lightweight TTS** | ONNX-based models (25-80 MB), CPU-optimized inference |

### Data Flow

```
Interview Flow:
1. User Consent → 2. Session Created → 3. MCQ Assessment
        ↓
4. Interview Starts → 5. AI Question Asked (TTS) → 6. User Speaks
        ↓
7. Speech Captured → 8. Transcribed (ASR) → 9. Video Analyzed
        ↓
10. Scoring Computed → 11. Next Question Asked
        ↓
12. [Repeat steps 5-11 for 5 questions]
        ↓
13. Final Report Generated (fused scores) → 14. Results Saved
```

## 📦 Installation & Setup

### Step 1: Clone Repository

```bash
git clone https://github.com/SALEM-ISMAIL-02/Interviewer.git
cd Interviewer
```

### Step 2: Create Virtual Environment

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### Step 3: Install Dependencies

```powershell
# Backend dependencies
pip install fastapi uvicorn pydantic pydantic-settings sqlalchemy numpy
pip install faster-whisper opencv-python mediapipe scipy kittentts

# Frontend dependencies
cd frontend
npm install
cd ..
```

### Step 4: Download Models & Binaries

Models are large (4-7 GB). The setup script downloads them:

```powershell
# One-time setup (downloads all models and binaries)
.\scripts\setup_windows.ps1

# Or skip downloads if you already have them:
.\scripts\setup_windows.ps1 -SkipDownloads
```

**Models downloaded:**
- `llama-2-7b.gguf` (4.2 GB) - LLM for questions/scoring
- `ggml-base.en.bin` (141 MB) - Whisper ASR model
- `kitten-tts-mini-0.8.onnx` (80 MB) - KittenTTS voice model (recommended, 80M parameters)

### Step 5: Configure Environment

Create `backend\.env`:

```env
# Database
DATABASE_URL=sqlite:///data/hirenest.db

# ASR (Speech Recognition)
MOCK_ASR=false
ASR_ENGINE=auto
FASTER_WHISPER_MODEL=base.en
FASTER_WHISPER_DEVICE=cuda
FASTER_WHISPER_COMPUTE=int8

# TTS (Text-to-Speech) - KittenTTS
KITTENTTS_MODEL=KittenML/kitten-tts-mini-0.8
KITTENTTS_VOICE=Jasper
TTS_ENGINE=kittentts

# LLM
MOCK_LLM=false
LLAMA_THREADS=6
LLAMA_MAX_TOKENS=512

# Scoring Weights
SCORE_WEIGHTS_CONTENT=0.50
SCORE_WEIGHTS_FLUENCY=0.20
SCORE_WEIGHTS_PROSODY=0.15
SCORE_WEIGHTS_NONVERBAL=0.15

# Audio/Video
AUDIO_CHUNK_SEC=1.5
VIDEO_FPS=6
```

## ⚙️ Configuration

### Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `MOCK_ASR` | `false` | Use mock ASR (testing only) |
| `MOCK_LLM` | `false` | Use mock LLM (testing only) |
| `ASR_ENGINE` | `auto` | `auto` \| `faster_whisper` \| `whisper_cpp` \| `mock` |
| `TTS_ENGINE` | `kittentts` | `kittentts` \| `piper` \| `pyttsx3` \| `browser` |
| `KITTENTTS_MODEL` | `KittenML/kitten-tts-mini-0.8` | KittenTTS model: mini (80M), micro (40M), nano (15M), nano-int8 |
| `KITTENTTS_VOICE` | `Jasper` | Voice: Bella, Jasper, Luna, Bruno, Rosie, Hugo, Kiki, Leo |
| `FASTER_WHISPER_DEVICE` | `cpu` | `cpu` \| `cuda` |
| `FASTER_WHISPER_COMPUTE` | `int8` | `int8` \| `int16` \| `float32` |
| `LLAMA_THREADS` | `6` | CPU threads for LLM inference |
| `LLAMA_NGP` | `0` | GPU layers (0 = CPU only) |

### GPU Acceleration (CUDA)

To enable GPU acceleration:

1. Install NVIDIA CUDA Toolkit 11.8+
2. Install cuDNN
3. Set `FASTER_WHISPER_DEVICE=cuda` in `.env`

## 🚀 Running the Project

```powershell
cd d:\interview\hirenest
```

## 🔌 API Endpoints

### MCQ Endpoints

#### Generate MCQ Questions
```http
POST /mcq/generate
Content-Type: application/json

{
  "job_title": "Senior Software Engineer",
  "candidate_id": "cand-001"
}
```

**Response:**
```json
{
  "session_id": "session-123",
  "job_title": "Senior Software Engineer",
  "questions_count": 20
}
```

#### Get MCQ Questions
```http
GET /mcq/{session_id}
```

**Response:**
```json
{
  "questions": [
    {
      "id": "q1",
      "question": "What is the time complexity of binary search?",
      "options": ["O(n)", "O(log n)", "O(n log n)", "O(1)"],
      "correct_option": 1
    }
  ]
}
```

#### Submit MCQ Answers
```http
POST /mcq/{session_id}/submit
Content-Type: application/json

{
  "answers": [1, 2, 0, 1, 2, 0, 1, 2, 1, 0, 1, 2, 0, 1, 2, 1, 0, 2, 1, 0]
}
```

**Response:**
```json
{
  "score": 85,
  "skills": {
    "Problem Solving": 0.92,
    "Data Structures": 0.88,
    "System Design": 0.75
  }
}
```

### Interview Endpoints

#### Start Interview
```http
POST /interview/start
Content-Type: application/json

{
  "job_title": "Senior Software Engineer",
  "candidate_id": "cand-001",
  "consent": true,
  "voice_preset": "Luna"
}
```

**Response:**
```json
{
  "session_id": "interview-456",
  "status": "ready"
}
```

#### End Interview
```http
POST /interview/{session_id}/end
Content-Type: application/json

{
  "expected_points": "Discussed architecture patterns"
}
```

**Response:**
```json
{
  "content_score": 8.5,
  "fluency_score": 7.8,
  "prosody_score": 7.2,
  "nonverbal_score": 8.1,
  "overall_score": 7.9,
  "recommendation": "STRONG_YES"
}
```

#### Get Available Voices
```http
GET /interview/voices
```

**Response:**
```json
{
  "default": "Jasper",
  "voices": ["Bella", "Jasper", "Luna", "Bruno", "Rosie", "Hugo", "Kiki", "Leo"]
}
```

## 🐛 Troubleshooting

### Issue: Speech Not Recognized

**Problem:** ASR returns `[mock — set MOCK_ASR=false...]`

**Solution:**
```powershell
# 1. Verify faster-whisper is installed
pip show faster-whisper

# 2. Set environment variable
$env:MOCK_ASR = "false"

# 3. Check health endpoint
curl http://127.0.0.1:8000/health

# Expected: "asr_engine": "faster_whisper"
```

### Issue: Voice Actor Not Changing

**Problem:** Selecting different voice but hearing same speaker

**Solution:**
```powershell
# 1. Verify voices are available
curl http://127.0.0.1:8000/interview/voices

# 2. Update KITTENTTS_VOICE in .env to one of:
# Bella, Jasper, Luna, Bruno, Rosie, Hugo, Kiki, Leo

# 3. Restart backend server
```

### Issue: Slow Performance / Freezing

**Problem:** Backend is lagging during interview

**Solution:**
```powershell
# 1. Reduce audio chunk size in .env
AUDIO_CHUNK_SEC=1.0

# 2. Reduce video FPS
VIDEO_FPS=3

# 3. Enable GPU (if available)
FASTER_WHISPER_DEVICE=cuda
LLAMA_NGP=30

# 4. Use lower-precision compute
FASTER_WHISPER_COMPUTE=int8
```

### Issue: Out of Memory

**Problem:** Python process crashes with memory error

**Solution:**
```powershell
# 1. Close other applications
# 2. Use CPU-only mode temporarily
$env:FASTER_WHISPER_DEVICE = "cpu"

# 3. Reduce video resolution
VIDEO_FPS=3

# 4. Increase virtual memory in Windows
```

### Issue: Models Not Found

```powershell
# 1. Re-run setup script
```

## 🎤 About KittenTTS

**HireNest** now uses **KittenTTS**, a lightweight, open-source text-to-speech engine optimized for offline use. Here's why:

### Why KittenTTS?

| Feature | Benefit |
|---------|---------|
| **Ultra-lightweight** | Only 25-80 MB models vs hundreds of MB for traditional TTS |
| **ONNX-based** | Runs efficiently on CPU without GPU requirements |
| **8 Natural Voices** | Bella, Jasper, Luna, Bruno, Rosie, Hugo, Kiki, Leo |
| **No External Dependencies** | Completely offline, no cloud API calls |
| **Fast Inference** | Real-time speech synthesis for interactive interviews |
| **Adjustable Speech Speed** | Control pacing with the `speed` parameter |
| **24 kHz Output** | High-quality audio synthesis |

### KittenTTS Models Available

| Model | Size | Speed | Quality | Use Case |
|-------|------|-------|---------|----------|
| **kitten-tts-nano** (15M) | 25 MB (int8) | ⚡ Fast | Good | Resource-limited systems |
| **kitten-tts-micro** (40M) | 41 MB | ⚡⚡ Medium | Very Good | Balanced performance |
| **kitten-tts-mini** (80M) | 80 MB | ⚡⚡⚡ Good | Excellent | Best quality (default) |

To switch models, update `KITTENTTS_MODEL` in `.env`:
```env
# Fast mode (nano - 25 MB)
KITTENTTS_MODEL=KittenML/kitten-tts-nano-0.8-int8

# Balanced (micro - 41 MB)
KITTENTTS_MODEL=KittenML/kitten-tts-micro-0.8

# Best quality (mini - 80 MB, default)
KITTENTTS_MODEL=KittenML/kitten-tts-mini-0.8
```

Learn more: [KittenTTS GitHub](https://github.com/KittenML/KittenTTS)
